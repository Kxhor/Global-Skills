# Taste Skill — Anti-Slop Frontend Framework

Whenever designing, building, or modifying frontends (landing pages, portfolios, marketing sites, redesigns, and components), apply Taste Skill principles:

1. **Brief Inference First:** Never jump to default styling. Infer page kind, audience, tone, and constraints. Output a one-line Design Read:
   `Reading this as: <page kind> for <audience>, with a <vibe> language, leaning toward <design system or aesthetic family>.`
2. **Three Core Dials:**
   - `DESIGN_VARIANCE` (1 = symmetry, 10 = artsy chaos; baseline: 7-8)
   - `MOTION_INTENSITY` (1 = static, 10 = physics/cinematic; baseline: 5-6)
   - `VISUAL_DENSITY` (1 = airy gallery, 10 = data cockpit; baseline: 3-4)
3. **Anti-Default Discipline:**
   - BANNED by default: AI-purple gradients, generic centered hero over dark mesh, 3 identical feature cards, generic glassmorphism on everything, Inter + slate-900.
   - Real typography pairings (Geist, Outfit, Cabinet Grotesk, Satoshi, or context-justified serif).
   - Real visual assets: generate images via tools or real photography, never div-based fake screenshots.
   - Respect a11y, WCAG contrast, and `prefers-reduced-motion`.
4. **Harmonization with Ponytail:**
   - Pair anti-slop visual distinction with clean, minimal, maintainable code. No unnecessary dependencies or bloated CSS frameworks.
